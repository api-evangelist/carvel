Now that you’ve deployed Kubernetes, how do you get apps up and running atop the container runtime? Carvel (formerly known as k14s), a collection of open-source tools for working with Kubernetes, is designed to answer this question. Carvel was born from frustration with existing tools ¶Carvel is a set of tools designed to ease lifecycle management of your Kubernetes workloads.
